# Live Password Validator
A simple password validator built with HTML, CSS and JavaScript.
# Features
- Checks if the password has at least 8 characters.
- Checks for at least one number.
- Checks for at least one uppercase letter.
- Shows and hide the password ussing the eye button.
- Clears the password when the Escape key is pressed.
# Built With
- HTML
- CSS
- JavaScript
